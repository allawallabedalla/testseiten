# Forschung 🔬

Hier werden Forschungsideen sauber und einheitlich abgelegt.

## Konvention

- **Eine Idee = ein Ordner** direkt unter `forschung/`.
- Der Ordnername ist ein kurzer, sprechender *Slug* in Kleinbuchstaben,
  Wörter mit Bindestrich getrennt – z. B. `forschung/fake-reviews-erkennung/`.
- Darunter dürfen **beliebig viele Unterordner** entstehen, ganz wie es
  die Idee braucht (Quellen, Notizen, Daten, Entwürfe, Experimente …).
- Jeder Ideen-Ordner enthält eine eigene `README.md`, die die Idee in
  ein paar Sätzen beschreibt (siehe Vorlage unten).

## Neue Idee anlegen

Kopiere den Vorlagen-Ordner und benenne ihn um:

```bash
cp -r forschung/_vorlage-idee "forschung/meine-neue-idee"
```

Danach die `README.md` im neuen Ordner ausfüllen und die Unterordner
nach Bedarf anpassen oder ergänzen.

> Tipp: Du kannst mir auch einfach den Namen einer Idee nennen – dann lege
> ich den Ordner samt Grundgerüst für dich an.

## Empfohlene Unterordner (optional)

Die Vorlage schlägt ein paar bewährte Unterordner vor. Nutze nur die,
die du brauchst, und erfinde neue dazu:

| Ordner        | Zweck                                             |
|---------------|---------------------------------------------------|
| `quellen/`    | Belege, Paper, Links, PDFs, Screenshots           |
| `notizen/`    | Eigene Gedanken, Zwischenstände, offene Fragen     |
| `daten/`      | Rohdaten, Auswertungen, Tabellen                   |
| `entwuerfe/`  | Texte, Skizzen, Konzepte im Werden                 |
| `experimente/`| Code, Prototypen, Tests                            |
